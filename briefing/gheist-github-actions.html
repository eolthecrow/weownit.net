Gheist: stolen GitHub tokens expose secrets through Actions

Wiz documents abuse of compromised tokens to extract repository secrets.

weownit.net editorial analysis · weownit.net publication: 2026-10-26 · Reviewed: 2026-10-26

Topic

GitHub · CI/CD · Secrets

Original source

Wiz Research ↗

In focus

Documented campaign

What was reported

According to Wiz, Gheist uses stolen tokens to introduce workflows that extract secrets through GitHub Actions logs.

Applicability and impact

Map repository access to downstream credentials and services. The assessment boundary must include the impact of changing credentials on deployments and operations.

What to check and remediate

  1. Preserve relevant evidence before cleanup and scope the access allowed by suspect tokens.
  2. Coordinate revocation and credential rotation with application owners.
  3. Review automation permissions and document post-remediation checks.
What to keep in mind

The assessment should follow systems accessible with exposed credentials.
