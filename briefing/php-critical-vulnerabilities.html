PHP: two critical vulnerabilities. What should you check before updating?

ENISA urges action on two RCE vulnerabilities. Internet-facing applications take priority.

weownit.net editorial analysis · weownit.net publication: 2026-10-26 · Reviewed: 2026-10-26

Topic

PHP · Web applications

Original source

PHP ↗ · ENISA ↗

In focus

Critical · Updates published

What was reported

PHP released fixes for CVE-2026-109618 and CVE-2026-109619 on 21 October. ENISA recommends immediate action.

Applicability and impact

Prioritize publicly reachable PHP applications and identify the actual runtime with its owner. A server header or CMS name alone is insufficient to establish whether a patched package is installed.

What to check and remediate

  1. Identify PHP runtimes in your inventory and confirm packages with the application administrator.
  2. Agree a change window, backup and rollback criteria; coordinate the update with the application team.
  3. Validate the service and version afterwards; also review PHP’s 23 October notice.
