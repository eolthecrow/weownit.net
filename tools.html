Export guidance

Use complete policy exports with their scope and related objects. Fortinet JSON requires REST response wrappers. Check Point policy data can be exported through mgmt_cli as JSON.

Fortinet: firewall policy/security-policy CLI export, including VDOMs. Palo Alto: config XML, including Panorama rulebases. Check Point: extracted access-rulebase and objects JSON; select related JSON files together. Archives and Gaia CLI are not supported.
