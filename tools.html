Format, coverage and limits
Shodan IPv4 host exports: one JSON object, an array, or one host object per JSONL line. Each host needs ip_str and data[]; each service needs port, transport tcp/udp and timestamp. Native Shodan timestamps without a suffix are treated as UTC, as documented by Shodan. Maximum 2 MiB / 5,000 services per export. Use the same IP set. Individual banner JSONL, gzip, Censys, IPv6 and empty-service exports are unsupported. Only service presence is compared; applications, certificates and CVEs are not assessed. Matching services cannot have older observations in the recent input. Cached observation windows can overlap; input position declares snapshot order.
{"ip_str":"192.0.2.10","data":[{"port":443,"transport":"tcp","timestamp":"2026-10-22T10:00:00Z"}]}
